# 📦 Supply Chain Demand Forecasting

## 🌐 Live Demo
[Supply chain deman forecasting app](https://04-demand-forecasting.streamlit.app/)

An XGBoost-based demand forecasting prototype that predicts future product demand using historical SKU sales and time-based features.

The project demonstrates an end-to-end forecasting workflow from historical sales data to model evaluation and an interactive Streamlit dashboard.

---

## 📌 Project Overview

The objective of this project is to demonstrate a machine-learning approach for forecasting product demand.

The pipeline follows:

```text
Historical SKU Sales
        ↓
Lag & Rolling Features
        ↓
Date-Based Features
        ↓
XGBoost Regression Model
        ↓
Model Evaluation
        ↓
Future Demand Forecast
        ↓
Streamlit Dashboard
```
## 📊 Dataset

The project uses synthetic daily SKU sales data generated by the training pipeline.

The generated dataset contains historical demand information that can be used to demonstrate forecasting without relying on private business data.

The generated sales dataset is saved as:

artifacts/sales_history.csv

⚠️ The dataset is synthetic and is intended for demonstration and software-validation purposes. Forecasting performance should not be interpreted as performance on real business data.

# 🧮 Feature Engineering

The forecasting model uses historical and calendar-based features including:

Lag 1 day
Lag 7 days
Lag 14 days
Lag 28 days
7-day rolling statistics
28-day rolling statistics
Day of week
Month
Historical demand

These features help the model capture recent demand patterns and recurring time-based behavior.

# 🤖 Model

The prototype uses XGBoost Regression.

XGBoost was selected for the MVP because it can efficiently learn nonlinear relationships from engineered time-series features and is relatively fast to train and demonstrate.

The project guide proposes more advanced forecasting approaches such as:

ARIMA/SARIMA
LSTM
Temporal Fusion Transformer (TFT)

These are considered future upgrades and are not implemented in the current MVP.

# 📈 Model Evaluation

The model is evaluated using:

MAE — Mean Absolute Error
RMSE — Root Mean Squared Error
WMAPE — Weighted Mean Absolute Percentage Error

Current training run:

MAE   = 9.50
RMSE  = 13.30
WMAPE = 6.17%

The evaluation uses a chronological forecasting setup rather than randomly shuffling the time-series data.

⚠️ These metrics are based on synthetic data and should not be interpreted as real-world supply-chain forecasting performance.

# 🖥️ Streamlit Dashboard

The project includes an interactive Streamlit application for exploring demand forecasts.

The dashboard allows users to provide forecasting inputs and generate future-demand predictions using the trained model.

The application loads the trained model from:

artifacts/demand_model.joblib

## ⚙️ Installation

Install the required dependencies:

pip install -r requirements.txt
▶️ Train the Model

Run:

python train.py

The training script generates the synthetic sales data, trains the XGBoost model, evaluates it, and saves the resulting artifacts.

Generated files:

artifacts/demand_model.joblib
artifacts/sales_history.csv
# 🚀 Run the Streamlit App

Run:

python -m streamlit run app.py

The application will open in the browser.

⚠️ Limitations

This is an internship-level forecasting prototype and has several limitations:

The default dataset is synthetic.
The model has not been evaluated on real business sales data.
External factors such as promotions, holidays, weather, competitor activity, and supply disruptions are not modeled.
The current implementation uses XGBoost rather than deep-learning forecasting architectures.
No real-time inventory or ERP integration is implemented.
No production API is included.
No cloud deployment or automated retraining pipeline is included.
No dedicated model-drift monitoring system is implemented.
